# План версии v3.0 — «Очиститель текста»

## Цель
Расширить MVP (v1.0–v1.2) функциями из дорожной карты «После MVP»,
опубликовать веб-версию в интернете и подготовить рекламные материалы.

## Новые функции

### 1. Форматирование JSON / XML / SQL
- Выпадающий список «Формат» в панели операций: выкл / JSON / XML / SQL.
- JSON: парсинг и переформатирование с отступами; при ошибке — понятное сообщение.
- XML: аккуратный вывод с отступами (простые и самозакрывающиеся теги, текстовые узлы).
- SQL: ключевые слова в верхний регистр, отступы для JOIN/AND/OR/ON и вложенных строк.

### 2. Скрытие личных данных
- Операция «Скрыть личные данные»: маскирует e-mail, телефоны, IP-адреса,
  номера карт и СНИЛС (замена на `[email]`, `[телефон]`, `[IP]`, `[карта]`, `[СНИЛС]`).

### 3. Подсветка изменений (дифф)
- Кнопка «Дифф» в панели результата: построчное сравнение исходного текста
  и результата (LCS), удалённые строки красным, добавленные — зелёным.

### 4. История буфера обмена
- Кнопка «История»: список последних 20 скопированных текстов (время + превью),
  клик восстанавливает текст в исходное поле, хранится локально.

### 5. PWA (для веб-версии)
- manifest.webmanifest + service worker: установка как приложения, работа офлайн,
  автономный режим на телефоне.

### 6. Версия и упаковка
- Версия 3.0.0, бейдж в шапке, новый портативный exe `Очиститель-текста-3.0.exe`.

## Публикация
- GitHub: публичный репозиторий `text-cleaner`, GitHub Pages → публичный URL.
- Web-версия: index.html + styles.css + app.js + manifest + sw (без node_modules).

## Реклама
- Баннер 1600×900 (рендер через Electron screenshot).
- Тексты постов для Telegram, VK, X (с реальной ссылкой после публикации).
- README.md как витрина проекта.

## Критерии готовности
- Все чистые функции покрыты Node-тестами.
- exe v3.0 собирается и запускается.
- Веб-версия доступна по публичному URL.
- Рекламные материалы готовы и содержат реальную ссылку.
