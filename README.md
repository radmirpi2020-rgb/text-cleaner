# Очиститель текста

Приводит скопированный текст в порядок за один клик. Всё работает локально:
никакие данные не покидают устройство — ни при работе в браузере, ни в
настольном приложении.

**v3.0** — веб-версия (PWA) и Windows-приложение (portable exe).

## Зачем это

Текст из PDF, сайтов, Word и почты приходит «грязным»: двойные пробелы,
переносы слов на концах строк, странные кавычки, HTML-теги, дубликаты строк.
Очиститель исправляет всё это одновременно и показывает статистику.

## Возможности

| Раздел | Что делает |
| --- | --- |
| Пробелы и строки | Убирает лишние пробелы, переносы, соединяет строки в абзацы, удаляет пустые строки |
| Разметка | Удаляет HTML и Markdown, нормализует кавычки и тире |
| Регистр | Нижний, ВЕРХНИЙ, с заглавной буквы, каждое слово |
| Строки | Сортирует строки, убирает дубликаты |
| Язык | Транслитерация кириллицы в латиницу |
| Конфиденциальность | Скрывает e-mail, телефоны, IP, номера карт и СНИЛС |
| Форматы | Переформатирует JSON, XML, SQL |
| Поиск и замена | Обычный текст или регулярные выражения |
| Дифф | Построчное сравнение исходного текста и результата (LCS) |
| Сценарии | Сохранение наборов операций под именем |
| История | Последние 20 скопированных текстов в буфере приложения |

Дополнительно: статистика (символы, слова, строки, время чтения), отмена
изменений, открытие файлов, копирование/скачивание результата, тёмная тема,
сохранение последнего текста — по желанию.

## Как пользоваться

1. Откройте веб-версию (ссылка ниже) или скачайте exe.
2. Вставьте или загрузите текст.
3. Включите нужные операции — результат пересчитывается мгновенно.
4. Скопируйте или скачайте очищенный текст.

Установка не требуется: веб-версия работает офлайн после первого открытия
(service worker), данные хранятся только на вашем устройстве.

## Ссылки

- Веб-версия: https://radmirpi2020-rgb.github.io/text-cleaner/
- Windows (.exe, portable, ~85 МБ): собирается командой `npm run build:win` → `dist/Очиститель-текста-3.0.exe`

## Разработка

```
npm install          # зависимости (Electron, electron-builder)
npm start            # запуск desktop-приложения
npm run build:win    # сборка portable exe -> dist/
npm run gen:icon     # перегенерация иконки
node tests/pipeline.test.js  # модульные тесты логики
```

Проект без библиотек для логики: преобразования — чистые функции в `app.js`
(модульно тестируются в Node), интерфейс — один HTML-файл без сборки.
